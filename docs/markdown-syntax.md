# Markdown 対応記法

adiary の Markdown パーサー（`lib/Satsuki/TextParser/Markdown.pm`）が対応する記法の一覧。
パーサーの作り直しと、そのテストはこの文書を仕様として扱う。

## 方針

- CommonMark / GFM のすべては満たさない。**Prettier v3 で整形した Markdown に現れる記法**を基本に、実際に使っている記法だけに対応する。
- 使われていない変則的な記法は切り捨てる。ただし、単純に対応できて Prettier で壊れないものは対応してよい。
- **対応しない記法は、エラーにせず普通の文章として表示する。** 例えば `* list` は箇条書きにならず、`* list` という文字のまま出る。

使用数は 2026-10-10 時点の Markdown 記事 745 件での数（コードフェンス内は除外）。

## 対応する記法

### ブロック

| 記法 | 書き方 | 使用数 | 補足 |
|---|---|---|---|
| 見出し | `# 見出し` 〜 `###### 見出し` | ─ | `#` の後に空白が必要（`#見出し` は文章になる） |
| 段落 | 空行で区切る | ─ | 段落内の改行は `<br>` になる。行末の2スペースに特別な意味は無い |
| 箇条書き | `- 項目` | 197記事 | 記号は `-` のみ |
| 番号付きリスト | `1. 項目` | ─ | 開始番号を反映する（`3.` から始まれば `<ol start="3">`） |
| チェックボックス | `- [ ] 項目` / `- [x] 項目` | ─ | |
| リストの入れ子 | 項目の内容の開始位置まで字下げ | 98記事 | 字下げ幅は記号の幅に合わせる（`- ` は2、`1. ` は3、`10. ` は4） |
| 項目の間に空行のあるリスト | | 48記事 | 各項目の中身が `<p>` になる |
| 項目内の複数ブロック | 項目の字下げに合わせて書く | 80記事 | コードフェンス、テーブル、段落などを項目の中に置ける |
| コードフェンス | ` ```言語 ` 〜 ` ``` ` | ─ | 3つ以上のバッククォート。開始と同じ長さ以上で閉じる（中に ` ``` ` を含めたいときは ` ```` ` を使う） |
| 引用 | `> 文章` | 64記事 | 入れ子（`> >`）も可 |
| テーブル | 下記参照 | 283記事 | |
| 区切り線 | `---` | ─ | |
| HTMLブロック | `<div>` などで始まる行 | 13記事 | 許可されたタグのみ（`info/allow_tags_article.txt`） |
| HTMLコメント | `<!-- -->` | 31記事 | |
| 脚注 | 本文に `[^id]`、定義は `[^id]: 内容` | 27記事 | |

#### テーブル

```markdown
| 左寄せ | 中央 | 右寄せ |
| :----- | :--: | -----: |
| a      |  b   |      c |
```

- 各行は `|` で始める。
- 2行目は区切り行（`-` と、位置揃えの `:`）。
- 空行を挟まず、段落やリスト項目の文章の直後から始めてもよい。

### adiary 独自の記法

adiary 独自の記法には、次の2種類がある。

| 種類 | 処理する場所 | 扱い |
|---|---|---|
| さつき記法のタグ（`[image:...]` など） | さつき記法パーサー（`Satsuki.pm`）。Markdown パーサーは各行を渡すだけ | タグ一覧（`?etc/satsuki_tags`、定義は `info/textparser_tags.txt`）にあるものはすべて使える。Markdown パーサーの作り直しの対象外 |
| 目次、続きを読む | Markdown パーサー | 下の表のとおり |

Markdown のインライン処理とタグの処理の順番によっては、タグが Markdown の記法と取り違えられる恐れがある。作り直しではこの点に注意する。

#### 画像と `<figure>`

Markdown の記事では、画像（`[image:...]`）は段落の中に出力されるため、キャプションが無ければ `<figure>` で囲まない（`<p>` の中に `<figure>` を入れるとHTMLとして不正になるため）。

- キャプションは、画像の後の2つ目以降の引数に `#` を付けて書く（`[image:S:フォルダ/:ファイル名:代替テキスト:#キャプション]`）。このときは `<figure>` と `<figcaption>` で囲む。
- さつき記法など、Markdown 以外の記事は今までどおり常に `<figure>` で囲む。
- テーマの minato / chie（画像リンクの装飾）と sumomo（画像の高さ揃えのJS）は `<figure>` を前提にしているため、Markdown の記事ではこれらの効果が無くなる。lyco テーマは `a[class^="tag-image"]` に余白を指定して対応済み。

#### Markdown パーサーで処理するもの

| 記法 | 書き方 | 使用数 |
|---|---|---|
| 目次 | `[*toc]` | 179記事 |
| 続きを読む | `====` または `=====` だけの行 | ─ |

#### よく使うタグ

| 記法 | 書き方 | 使用数 |
|---|---|---|
| 画像アルバムの画像 | `[image:S:フォルダ/:ファイル名:代替テキスト]` | 384記事 |
| YouTube | `[youtube:動画ID]` | 10記事 |
| URL の埋め込み | `[&URL]`（YouTube、X、ニコニコ動画などは埋め込み、それ以外はタイトル付きリンク） | 2記事 |
| ファイル | `[file:...]` | 3記事 |
| バナー | `[info:文章]` / `[warn:文章]` / `[error:文章]` | 5記事 |

## 対応しない記法

いずれも使用数は 0。普通の文章として表示する。

| 分類 | 記法 | 代わりの書き方 |
|---|---|---|
| 見出し | 閉じ `#` 付き（`## 見出し ##`） | `## 見出し` |
| 見出し | 行頭に空白のあるもの（`  ### 見出し`） | `### 見出し` |
| 見出し | 下線で書くもの（`===` / `---`） | `#` / `##` |
| コードブロック | 4スペースのインデントで書くもの | コードフェンス |
| コードブロック | `~~~` のフェンス | ` ``` ` |
| コードブロック | 数式（` ```math `） | ─ |
| コードブロック | ファイル名の指定（` ```言語:ファイル名 `） | ─ |
| 区切り線 | `***` / `___` | `---` |
| リスト | `*` / `+` の記号 | `-` |
| リスト | `1)` 形式 | `1.` |
| リスト | 字下げせずに前の行に続ける書き方（怠惰な継続） | 字下げする |
| 引用 | `>` を付けずに前の行に続ける書き方（怠惰な継続） | 各行に `>` を付ける |
| テーブル | 行頭に `\|` の無いもの | 各行を `\|` で始める |
| 強調 | `*強調*` | `_強調_` |
| 強調 | `__太字__` | `**太字**` |
| 強調 | `***太字斜体***` | ─ |
| リンク | 参照形式（`[文字][id]` と `[id]: URL`） | `[文字](URL)` |
| リンク | タイトル付き（`[文字](URL "タイトル")`） | ─ |
| リンク | 囲まずに書いた URL の自動リンク | `<URL>` か `[文字](URL)` |
| 改行 | 行末の `\` | 不要（段落内の改行は `<br>` になる） |
| adiary 独自 | 注釈 `((注釈))` | 脚注 `[^id]` |

## テスト

この文書の各項目は `t/markdown/*.txt` のテストケースになっている。

```sh
prove t/markdown.t                       # 仕様のテスト
perl t/tools/corpus_diff.pl              # 手元の全記事で、HEAD と作業ツリーの出力を比べる
perl t/tools/corpus_diff.pl --diff       # 変わった記事の差分も表示する
```

- 今のパーサーが満たしていない項目は、ケースに `--- todo:` を付けている（失敗しても全体は成功扱い）。対応したら `--- todo:` の行を消す。
- `t/tools/corpus_diff.pl` は記事データ（git の管理外）を直接読むので、記事の中身はリポジトリに含まれない。
