# lyndbaumからのバックポート候補

lyndbaum（`~/develop/perl/lyndbaum`）にある機能のうち、adiary-extendsに取り込めそうなものをまとめた。2026-10-20時点の調査。

## 前提

- lyndbaumはSQLiteを使う一から書き直した設計で、adiaryのSatsukiとは作りが違う。コードをそのまま移すのではなく、同じ動きをadiary側で書き直す。
- ライセンスはどちらもAGPLv3なので、取り込んでも問題ない。
- 主な出どころは、lyndbaumの`docs/compat-diffs.md`（旧システムとの意図的な差分）と、各版のコミットメッセージ。
- 取り込み済み、または作業中のもの：
  - コードスパンの中の`\`（`2550dc5f`）
  - 脚注記法（`7b3a21b6`）
  - 表のセルの中の`\|`（`patch/markdown-parser`で作業中、未コミット）
  - Aの残り（リンクの角括弧と括弧、許可しない生のタグ、項目の先頭の`>`、空の`[*toc]`）（`patch/markdown-parser`で作業中、未コミット）
- レスポンシブデザイン・Markdownパーサー・バックリンク・Fancyboxのスクリプトダイエットが目的
  - 直せるなら管理画面のメインUIも直していいかもしれないが規模がデカそう？
  - ギャラリーは一旦そのままにしておく

## A. パーサーの不具合修正

小さくて取り込みやすい。いずれも今のadiaryのパーサーで出力を確かめた。

| 項目                                         | 入力の例                     | 今のadiaryの出力                               | lyndbaumの出力     | 規模   |
| -------------------------------------------- | ---------------------------- | ---------------------------------------------- | ------------------ | ------ | ------------------------ | --- |
| リンクの文字の中の角括弧                     | `[a [b] c](http://x.jp/)`    | リンクにならず、そのまま文字で出る             | リンクにする       | 小     |
| リンク先の入れ子の括弧                       | `[t](http://x.jp/a_(b_(c)))` | `href="http://x.jp/a_(b_(c"`になり、`))`が余る | 対応する`)`まで    | 小     |
| 許可しない生のタグ                           | `<M>`、`<x86 Panther Lake>`  | タグのまま出る                                 | 文字として表示する | 小〜中 |
| リストの項目の先頭の`>`                      | `- > q1`                     | `<li>&gt; q1</li>`（文字になる）               | 引用にする         | 中     |
| 目次に入る見出しが無い`[*toc]`               | `[*toc]`だけで見出し無し     | 空の`<ul class="toc"></ul>`                    | 何も出さない       | 小     |
| 表のセルの中の`\|`（コードスパンの中を含む） | ``                           | `a \| b`                                       | ``                 | 作業中 | `\|`を縦棒として表示する | ―   |

## B. 仕様の変更

入れるかどうか、先に決める必要がある。

| 項目                     | 今のadiary                                                             | lyndbaum                                                      | 備考                                                                       |
| ------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 番号付きリストの開始番号 | `3.`から書いても1から始まる                                            | `<ol start="3">`                                              | 書いた番号のとおりに出す                                                   |
| 空行を挟んだリスト       | 項目ごとに`<p>`を付ける（`- a`、`- b`、空行、`- c`で`a`だけ`<p>`無し） | CommonMarkと同じく、リスト単位で全項目を`<p>`にする           | GitHubやVS Codeのプレビューと同じ表示になる                                |
| 見出しのID               | `## 見出し [#l7a712f2]`の`[#…]`が文字で出て、IDにも混ざる              | `[#識別子]`をIDにし、画面には出さない。無ければ保存時に付ける | 見出しの文字を変えてもリンクが壊れない。保存時の自動付与まで入れると中規模 |
| `_強調_`の扱い           | CommonMarkと同じ（`snake_case_name`は強調にならない）                  | 同じ                                                          | 対応は要らない                                                             |

## C. パーサー以外で取り込めそうなもの

| 項目                                | 内容                                                            | 規模・備考                                          |
| ----------------------------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| 参照元（バックリンク）              | その記事へリンクしている記事の一覧を記事の下に出す              | 中。adiaryには見当たらない                          |
| 目次の追従表示                      | スクロールしても見出しの目次がついてくる                        | 小〜中。JSとテーマが中心                            |
| 段を飛ばした見出しの警告            | `#`の無い`##`などを、編集の画面で指摘する                       | 小〜中                                              |
| コードの色付けの言語の別名          | `ps1`→`powershell`、`c#`→`csharp`（大文字と小文字は区別しない） | 小。数行で済む                                      |
| 画像の拡大表示をLythumbに置き換える | FancyboxからLythumb-viewer（AGPLv3、自作）へ                    | 中。属性が`data-fancybox`から`data-lythumb`に変わる |
| コメントの`>>N`のリンク             | `#cN`へのリンクにする                                           | 小。adiaryにすでに同じものがあるかは未確認          |
| URLを含むコメントを承認待ちにする   | スパム対策。リンクに`rel="nofollow ugc noopener noreferrer"`    | 中。adiaryのコメント機能をどこまで使うか次第        |
| パスワードのbcrypt化                | セキュリティ強化、やってもやらなくてもどうでもよさそうではある  | 小。恐らく私しかユーザーがいないので影響はない      |

## D. 取り込むのが難しい、または要らないもの

### 対応しない

- SQLiteを前提にした階層タグとファセット検索（閉包テーブル`tag_paths`）
  - adiary側を採用するため対応しない
- メディアブラウザ（ドラッグでの移動、フォルダの操作、範囲選択など）
  - adiary側を採用するため対応しない
- adiaryからのマイグレーション
  - 不要
- サイドバーのキャッシュなどの速度改善
  - adiaryは既に早いので対応不要

### adiaryにすでにあるもの

- FastCGI（`adiary.fcgi`）
- サイトマップ（`plugin/sitemap`）
- 前後の記事へのリンク
- `<head>`に入れるHTML（`dem_javascript`などのプラグインが近い）
- 新着コメントの通知

## 調べ方

Aの出力は、`t/lib/MarkdownTest.pm`の`parse_md`に各入力を通して確かめた（`sectioning=0`）。
取り込むときは、先に`t/markdown/*.txt`へテストケースを書いてから直す。
