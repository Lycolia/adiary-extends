- **閲覧画面**: `?_theme=`のクエリでテーマを切り替えられるのを、ブログの管理者だけにした（デザイン編集のテーマのプレビュー用）

  - 扱う形式は、JPEG、PNG（APNGを含む）、GIF、WebP、AVIF
  - 画像の拡張子の見本（`album_image_ext`）を`jpg, jpeg, gif, png, apng, webp, avif`にした（`ico`、`tif`、`tiff`を外し、`avif`を追加）。`adiary.conf.cgi`は自動では変わらないので、手で直す
- **その他**: 転送（`redirect()`）の後ろに、500のエラーや、ページ全体がもう一度付いていたのを直した
- **閲覧画面**: ソーシャルボタンを見直した
  - TwitterのボタンをXのボタンにした（投稿画面`x.com/intent/tweet`へのリンク）
  - ボタンは画像をやめ、それぞれのサービスの色の地に、ロゴやマークと文字をCSSで出すようにした。はてなブックマークは、公式のボタンと同じ「B!ブックマーク」の絵を使い、件数もボタンの中に出す
  - 件数の表示は、はてなブックマークだけにした。Twitterは件数を読むAPIが2015年に止まり、Facebookはアクセストークンが要るようになり、どちらも件数がいつも「-」か「0」だった
  - はてなブックマークの件数は、はてなが今案内しているAPI（`bookmark.hatenaapis.com/count/entry`）から読む
  - 外部のスクリプトは読み込まない。訪問者の情報がXやFacebookに送られるのは、ボタンを押したときだけ
  - リンク先は、JavaScriptで組み立てるのをやめ、サーバー側で記事のURLまで入れるようにした
  - Xの「フォロー推奨ID」が、設定した値ではなく空で送られていたのを直した
- **その他**: 動かなくなった外部のサービスとの連携を削除した
  - Twitter通知プラグイン（`twitter_post`）：Twitter API v1.1が使えなくなったため。システムアップデートで、入れたままのブログから外す
  - サイトマップの、検索エンジンへの更新の通知（ping）：受け口が止まったため。サイトマップの生成は残す
  - ソーシャルボタンのPocket：Pocketが終了したため
  - Google Analyticsの旧UA（Universal Analytics）のID：UAが終了したため。GA4は残す。静的HTMLのエクスポートの「Google Analyticsを埋め込む」はGA4を見るようにした（今までは、選ばなくてもGA4が埋め込まれていた）
  - 記事テーブルの使われていなかった`revision`のカラムを、定義から外した
- **その他**: AMPの機能を削除した
  - Googleの検索で、AMPのページが有利でなくなったため（2021年）。プラグインも手入れされておらず、終了したUniversal Analyticsの埋め込みが残っていた
  - システムアップデートで、AMPのプラグインを入れたままのブログから外し、記事のテーブルに足したカラムも消す
  - 記事の本文に書けるタグからAMPのタグ（`amp-ad`など）を外し、AMP版にだけ出す記法（`amp`、`for-amp`）も削除した
  - AMP版のURL（`?amp`）は、ブログのトップへ転送される

  - 画面はブログ管理者だけだったが、保存の処理は編集者にも許されていて、POSTを直接送ればブログ全体のCSSや`<head>`を書き換えられた

  - システムアップデートでプラグインを入れ直し、メニューを作り直すイベントも外す

- **その他**: ブログの詳細設定のFacebookの項目（`fb_admins`、`fb_app_id`）を削除した
  - Facebookのドメインインサイト（もう無い）のための項目だったため

  - 360度写真用ビューア（`sp_view360`）は、この記法で貼った画像を見回せるようにする。`view360`のクラスを付けたリンクの画像も今までどおり対象
